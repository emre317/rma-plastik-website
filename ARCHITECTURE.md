# RMA Digital Architecture

## Positioning
RMA is presented as an industrial polyethylene solutions manufacturer, not a simple product catalogue.

## Primary discovery paths
1. Products
2. Industries
3. Technologies

## Homepage sequence
Hero -> Proof/Stats -> Technologies -> Products -> Industries -> Engineering -> Facilities -> Quality/Global (next phase) -> CTA.

## UX principles
- Industrial, architectural visual language
- Strong typography and real manufacturing imagery
- Technical information close to commercial CTAs
- Minimal decorative UI
- Mobile-first responsive behavior
